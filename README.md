# Pontuação — Tribo de Levi (FJU)

Dashboard da pontuação da Tribo de Levi, com memória de cálculo semana a semana.

**Acesse:** https://thallesdaniel.github.io/pontuacao_levi/

## Como atualizar todo mês

Todos os dados ficam no objeto `DADOS`, no topo do script do `index.html`. Adicione a nova semana e as atividades (quantidade × valor unitário) e faça o commit na `main`. O GitHub Pages republica sozinho em 1 ou 2 minutos.
